# Day 5 – College Club Website (CSS Fundamentals)

## Project Overview
This project is an improved and styled version of my Day 4 College Club Website. It is designed to provide students with information about college club activities, events, and registration.

The website uses HTML, CSS, and JavaScript to create an attractive, user-friendly, and responsive experience.

## Project Name
`506-anushka-webdev-day05-club-site-styled`

## Technologies Used
- HTML5 – Website structure
- CSS3 – Styling and layout
- JavaScript – Basic interactivity
- Google Fonts – Typography
- Git and GitHub – Version control

## Website Pages
- **Home:** Introduction to the college club.
- **About:** Information about the club.
- **Contact:** Contact information.
- **Registration:** Student registration form.

## CSS Fundamentals Practiced
- External CSS stylesheet
- Element, class, ID, and descendant selectors
- CSS cascade and specificity
- Typography and colour combinations
- CSS custom properties (variables)
- Responsive design using media queries
- Spacing, margins, padding, and borders
- Debugging using browser Developer Tools
