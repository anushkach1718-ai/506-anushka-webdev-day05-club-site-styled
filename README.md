# Day 5 – College Club Website (CSS Fundamentals)

## Project Overview
This project is an improved and styled version of my Day 4 College Club Website. It uses HTML, CSS, and JavaScript to create an attractive, user-friendly, and responsive college club website.

## Project Name
506-anushka-webdev-day05-club-site-styled

## Technologies Used
- HTML5 – Website structure
- CSS3 – Styling and layout
- JavaScript – Basic interactivity
- Google Fonts – Typography
- Git and GitHub – Version control

## Website Pages
- **Home:** Introduction to the college club.
- **About:** Information about the club.
- **Events:** Details about club activities and events.
- **Registration:** Registration form for students.

## CSS Fundamentals Practiced
- External CSS stylesheet.
- Element, class, ID, and descendant selectors.
- CSS cascade and specificity.
- Typography and colour combinations.
- CSS custom properties (variables).
- Responsive layouts using media queries.
- Spacing, margins, padding, and borders.
- Debugging using browser Developer Tools.

## How to Run the Project
1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser.
4. Use Live Server for the best development experience.

## Learning Outcomes
- Learned to style websites using external CSS.
- Practiced different CSS selectors.
- Understood CSS specificity and the cascade.
- Learned to use CSS variables for consistent design.
- Improved website appearance and responsiveness.
- Practiced debugging with browser Developer Tools.
